# 🎨 Tattoo Studio

Site institucional moderno para um estúdio de tatuagem, desenvolvido com **React + Vite**, com foco em design visual, animações suaves e navegação fluida entre seções.

---

## 🚀 Tecnologias

Este projeto foi construído com:

- ⚛️ **React**
- ⚡ **Vite**
- 💅 **Tailwind CSS**
- 🎞️ **Framer Motion** (animações)
- 🔗 **React Router DOM**

---

## 📁 Estrutura do Projeto

tattoo_studio/
├── public/
├── src/
│ ├── assets/ # imagens e ícones
│ ├── components/ # componentes reutilizáveis (Header, Footer, etc)
│ ├── pages/ # páginas (Início, Artistas, Galeria, FAQ, etc)
│ ├── data/ # dados estáticos (lista de artistas)
│ ├── hooks/ # hooks personalizados
│ └── main.tsx # ponto de entrada da aplicação
├── package.json
└── vite.config.js

---

## 🧠 Funcionalidades

- 🖼️ Galeria de tatuagens organizada por artista  
- 👩‍🎨 Página individual para cada tatuador  
- 📜 Animações suaves ao navegar entre seções  
- 📱 Layout totalmente **responsivo**  
- 🌗 Design limpo e moderno inspirado em estúdios reais  

---

## 💻 Como executar o projeto localmente

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/IgorBern02/tattoo_studio.git
cd tattoo_studio
npm install
npm run dev
```

Acesse em: http://localhost:5173
